# ObscuriX-v1.2.0
<p align="center">
  <img src="https://img.shields.io/badge/Language-JS-blue.svg" alt="Bash">
</p>

Ce projet est un bot Minecraft multifonction pensé pour tourner sous Node.js de manière simple et accessible. Il repose sur la librairie MineFlayer, qui permet de créer et contrôler des bots très facilement.

<p align="center">
Installation  
</p>

1) Télécharge et installe Node.js.

2) Installe les plugins nécessaires au bon fonctionnement du bot en tapant cette commande dans ton terminal :
npm install mineflayer mineflayer-pathfinder mineflayer-pvp mineflayer-armor-manager

3) Clone le projet sur ta machine avec Git :
git clone https://github.com/0xTPy/ObscuriX-v1.2.0.git

<p align="center">
Utilisation
</p>

Le bot est multifonction et peut être contrôlé directement depuis le terminal :

PVP: Tape !pvp <joueur> pour lancer un combat. Grâce au plugin d'armure, il s'équipe tout seul si tu lui jetteras des pièces d'armure directement.

Arrêt: Tape !stop pour stopper le bot proprement.

<p align="center">
Prochaine mise à jour
</p>

La prochaine mise à jour intégrera le pathfinding. Si tu connais Baritone, tu vois exactement de quoi le bot sera capable. Si tu ne connais pas, pour faire simple, on pourra lui donner des coordonnées X, Y, Z pour qu'il s'y rende tout seul, lui dire de suivre un joueur ou même de miner des blocs.
