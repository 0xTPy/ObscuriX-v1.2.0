# ObscuriX-v1.2.0
<p align="center">
  <img src="https://img.shields.io/badge/Language-JS-blue.svg" alt="Bash">
</p>

Ce projet est un bot Minecraft multifonction pensé pour tourner sous Node.js de manière simple et accessible. Il repose sur la librairie MineFlayer, qui permet de créer et contrôler des bots très facilement.

<p align="center">
INSTALLATION  
</p>

1) Télécharge et installe Node.js.

2) Clone le projet sur ta machine avec Git :
   ```bash
   git clone https://github.com/0xTPy/ObscuriX-v1.2.0.git

4) Lance le programme avec la commande:
   ```bash
   cd ObscuriX-v1.2.0

   npm install mineflayer mineflayer-pathfinder mineflayer-pvp mineflayer-armor-manager

   node obscurix
<p align="center">
UTILISATION
</p>

Le bot est multifonction et peut être contrôlé directement depuis le terminal :

PVP: Tape !pvp [joueur] pour lancer un combat. Grâce au plugin d'armure, il s'équipe tout seul si tu lui jettes des pièces d'armure directement.

Arrêt: Tape !stop pour stopper le bot proprement.
